# 封面与开头黄金几秒

> 来源：做一条「豆包 × WorkBuddy 付费指南」竖版视频时，第一版拿小票抬头和日期开场，被指出「开头不够吸引人，开头应该是个封面」，按「话题 + Hook + 可信度」的开头诊断法重做后，规则沉淀在这里。
>
> 开头和封面决定观众会不会看下去，所以要在第 2 步出方案时就定下来，制作时第一个做，不要留到最后补。

## 一、第一帧就是封面

短视频在信息流里先被看到的是第一帧或封面图，所以第 0 帧必须能直接当封面用。

### 构成（竖版，从上到下）

1. **话题标签**：一个小胶囊，写主体是谁（豆包 × WorkBuddy）。

2. **大字标题**：最多两行。第一行是话题（AI 会员），第二行是态度或悬念（先别急着买），第二行用色块反白加重。竖版字号 170–210px。

3. **主体视觉**：话题里最具体的东西，比如价签、产品界面、数字，占画面中部三分之一以上，数字要大。

4. **反差贴纸**（可选）：把开头旁白里的反差做成贴纸，在开头动画里贴上去（¥99 划掉、贴 ¥70；贴 ¥0 免费版）。

5. **内容预告**：底部一行 2–3 个小标签，说清视频里有什么（免费额度 · 会员档位 · 省钱方法）。

横版 16:9 也是这几样，改成左边标题、右边主体。

### 硬要求

- **第 0 帧就是完整构图**：所有元素已经在位，不带字幕，不从空画面淡入。开头动画只在这个构图上加动作，比如元素跳一下、划线、贴纸。

- **风格**：亮底高对比（比如亮黄底、黑字、红色块），和正文画面区分开，但用同一套配色。

- **安全区**：竖版 1080×1920 时，标题和主体放在 y 240–1680 之间（平台会裁成 3:4）。顶部 200px 和底部 240px 只放被遮住也无所谓的东西。抖音右侧按钮栏大约在 x > 900、y 900–1500，关键信息别放那里。

- **禁止**：片头抬头、日期、版本号、账号水印、产品 logo、「第 X 期」、空白纸面、深色背景居中一行字。日期这类时效信息放进正文结尾或简介。

- **封面和标题分工**：封面给人看，走好奇和共鸣（先别急着买），不塞搜索词；标题给平台搜索看，覆盖关键词，写在 `publish.txt`。

### 导出封面图

页面里加一个开关：地址带 `?cover=1` 时不画字幕。开头动画走完、贴纸都贴上之后，渲一张静帧作为上传平台用的封面：

```
python3 scripts/render.py "index.html?cover=1" "out/$(python3 scripts/topic_name.py out/publish.txt)-封面.png" --still <开头动画结束后的秒数> --size 1080x1920
```

视频第 0 帧是这张图没有贴纸的版本，两者构图一致。

## 二、开头黄金几秒

### 开头公式

**开头 = 话题（讲什么）+ Hook（为什么看）+ 可信度（为什么信你）**，三样在前 3–5 秒都要出现。

**前 5 秒必须是一句暴论**：观众没那么多耐心，第一句话就要是一个反共识、敢下结论的硬判断，比如「2026 年了，还在对话框里跟 AI 聊天，就是在用最落后的方式用 AI」。暴论要能被正文撑住，不能是标题党；用直接陈述，不用反问。

### 五条法则

0. **第一句就是暴论**：5 秒内说完，见上。

1. **独立成立**：不假设观众看过标题和封面，第一句话里就要有话题（「豆包会员 68，WorkBuddy 会员 99」）。

2. **留悬念，不给答案**：头几秒抛反差或问题，结论留给正文。反例：第 8 秒就说「大部分人一分钱都不用花」，观众已经拿到答案，就没理由往下看了。

3. **用素材里最硬的东西**：优先级是晒结果加反转 > 数据冲击、前后反差、金句 > 权威背书 > 痛点。数字放在第一句。素材只能来自原材料，不编。

4. **口播友好**：直接陈述，不自问自答，不用书面语，不说「今天我们来聊聊」，不做自我介绍。

5. **给一个承诺**：开头最后交代看完能带走什么、要多久（「三分钟给你算清楚」），然后转场进正文。

### 时间结构（竖版知识类，开头约 15 秒）

| 时段 | 旁白 | 画面 |
|---|---|---|
| 0–5 秒 | 一句暴论（带话题，最好带一个数字或反差） | 封面已经在位；念到关键词，对应元素跳一下或被划掉 |
| 5–10 秒 | 反差或悬念 | 把反差做成画面动作：划掉、贴纸、对比 |
| 10–15 秒 | 承诺 | 标题轻轻一跳，然后转场进正文 |

画面动作跟着旁白里的词走，做法见 craft-rules.md「有配音时的画面文字」。没有配音的片子，第一句旁白换成封面上的大字和第一个动作，0–3 秒内同样要出现话题和数字。

### 写之前先查素材

开头写不好，多半是内容本身缺素材。出方案前先从原材料里找这几样：

- 有冲击力的数字

- 前后反差

- 能独立成立的金句

- 权威背书

- 目标人群的痛点

一样都没有，就先告诉用户补素材，不要硬写开头。装了开头优化类的 skill（比如 dbs-hook）时，可以先用它出 10–15 条候选开头，再挑一条。

### 例子

| | 旁白 | 第一帧 |
|---|---|---|
| 改前 | 豆包开始收钱了，最便宜的会员 68 一个月……结论很简单：大部分人一分钱都不用花 | 小票抬头「AI 会员价目表 2026-10-14」 |
| 改后 | 豆包会员 68，WorkBuddy 会员 99。同一个 WorkBuddy 会员，有人 70 块就买到了；还有人只用免费版，一分钱没花，照样够用。这两家到底该不该付钱、付哪一档，三分钟给你算清楚。 | 黄底封面「AI 会员 / 先别急着买」加两张价签，念到 70 划掉 ¥99、贴 ¥70，念到免费版贴 ¥0 |

## 三、自检清单

- [ ] 第 0 帧截图能直接当封面用：有大字、有主体，没有日期抬头，没有字幕

- [ ] 缩到 360px 宽，标题和数字还看得清

- [ ] 前 5 秒是一句暴论：反共识、有话题、直接陈述，正文撑得住

- [ ] 前 15 秒没有把正文的结论说出来

- [ ] 开头没有自问自答、没有「今天我们来聊聊」、没有自我介绍

- [ ] `out/<主题名>-封面.png` 已导出，和视频第 0 帧是同一套构图
